Privacy Policy

Effective date: September 6, 2026
Applies to: PolishPDF Chrome Extension — Build 2.0

Your documents stay yours.

PolishPDF is designed to let users edit PDF documents directly inside Chrome and from PDF attachments in Gmail while minimizing access to user data.

PDF processing is performed locally in the user's browser. PolishPDF does not operate a server that uploads, stores, or processes users' PDF documents.

1. Overview

PolishPDF is a Chrome extension that allows users to open, edit, annotate, sign, highlight, whiteout, reorder, manage, save, and download PDF documents.

PolishPDF also integrates with Gmail so that a user can select a PDF attachment in a Gmail compose window, open that PDF in PolishPDF, edit it, and return the edited PDF to the same Gmail compose workflow.

PolishPDF does not require users to create a PolishPDF account.

PolishPDF does not maintain a cloud database containing users' PDF files, document contents, email contents, or document edits.

2. Data handled by PolishPDF

PDF and document content

PolishPDF may process the following information locally on the user's device:

  • PDF files that the user chooses to open
  • Text contained within those PDFs
  • Images contained within those PDFs
  • Annotations
  • Signatures added by the user
  • Highlights
  • Whiteouts
  • Page order
  • Shapes and markings
  • Other edits made by the user

This information is processed only for the purpose of providing the PDF editing functionality requested by the user. PolishPDF does not upload this document content to a PolishPDF-operated server.

Gmail page content

When PolishPDF is used with Gmail, the extension may access limited elements of the Gmail compose interface that are necessary to:

  • detect a PDF attachment;
  • display the PolishPDF editing option;
  • open the PDF selected by the user; and
  • return the edited PDF to the Gmail compose workflow.

PolishPDF does not use Gmail access to read users' inboxes, monitor email activity, build profiles, or collect unrelated email content.

Extension settings and local state

PolishPDF may store limited extension settings, preferences, and temporary editor state using Chrome's local extension storage. This information is used only to provide and maintain PolishPDF functionality.

3. Information PolishPDF does not collect

PolishPDF does not intentionally collect:

  • passwords;
  • authentication credentials;
  • authentication cookies;
  • payment card information;
  • financial account information;
  • health information;
  • precise location;
  • browsing history for unrelated websites;
  • advertising identifiers; or
  • information for behavioral advertising.

PolishPDF does not sell user data or build advertising profiles.

4. Gmail access

PolishPDF requests access to Gmail only where required to provide its user-facing PDF attachment editing workflow.

This access allows PolishPDF to detect a PDF attachment selected by the user, open that document in the PolishPDF editor, and return the edited PDF to the Gmail compose workflow.

PolishPDF is not designed to:

  • read a user's inbox for unrelated purposes;
  • collect email conversations;
  • monitor who the user communicates with;
  • create profiles based on email activity; or
  • monitor general browsing behavior.

5. Chrome PDF access

When a user opens a supported PDF through Chrome, PolishPDF may access the PDF resource necessary to display and edit that document.

This access is used only to provide the PDF editing functionality requested by the user. PolishPDF does not use this access to collect or create a history of websites visited by the user.

6. Local PDF processing

PDF rendering and editing take place on the user's device.

The current version of PolishPDF does not upload users' PDF document contents to a PolishPDF-operated backend for document processing or storage.

When a user downloads or saves an edited PDF, the resulting file is saved to the location selected or controlled by the user.

When a user returns an edited PDF to Gmail, the resulting document is provided back to the Gmail workflow requested by the user and is then subject to Google's applicable terms and privacy practices.

7. Downloads

PolishPDF uses Chrome's download functionality when a user explicitly chooses to download or export an edited PDF. PolishPDF does not automatically download files without a user action.

8. Local storage

PolishPDF may use Chrome extension storage to maintain:

  • extension settings;
  • user preferences;
  • editor preferences; and
  • local state necessary for the extension to function.

This information is not used for advertising or user profiling.

9. PDF.js and third-party open-source code

PolishPDF uses Mozilla PDF.js 3.11.174 for PDF rendering.

In the current Build 2.0 configuration, PDF.js may be loaded from cdnjs.cloudflare.com within a sandboxed editor page.

This network request downloads the PDF.js library code required for PDF rendering. PolishPDF does not intentionally transmit the contents of the PDF being edited to cdnjs as part of this request.

Like normal internet requests, the third-party CDN provider may receive standard technical connection information such as an IP address and browser-related request information according to its own privacy practices.

The sandboxed editor page does not have privileged access to Chrome extension APIs.

10. Data retention

PolishPDF does not operate a server-side database that stores users' PDF documents, Gmail content, or document edits.

Document information may temporarily exist in browser memory while the PDF editing session is active. Extension settings or preferences may remain in Chrome's local extension storage until they are changed, cleared, or the extension is removed.

11. Data sharing and sale

PolishPDF does not:

  • sell user data;
  • transfer user data to data brokers;
  • transfer user data for personalized advertising;
  • use user data to determine creditworthiness; or
  • use user data for lending purposes.

12. Advertising and analytics

PolishPDF does not use document contents or Gmail contents for advertising.

The current release does not use advertising SDKs to build user profiles. PolishPDF does not use users' PDF contents to train a PolishPDF-owned artificial intelligence model.

13. Security

PolishPDF uses Chrome Manifest V3 and is designed to minimize the permissions and data access required to provide its PDF editing functionality.

PDF document processing is designed to remain on the user's device rather than requiring documents to be uploaded to a PolishPDF-operated document-processing server.

The PDF editor uses a sandboxed environment to separate relevant editor functionality from privileged Chrome extension APIs.

14. User choices and controls

Users control which PDFs PolishPDF opens and edits. Users may:

  • choose which PDF to edit;
  • close the editor without saving;
  • choose whether to download an edited PDF;
  • choose whether to return an edited PDF to Gmail;
  • manage PolishPDF's site permissions through Chrome;
  • clear extension data through Chrome; and
  • uninstall PolishPDF at any time.

15. Chrome Web Store Limited Use disclosure

PolishPDF's use of information received from Chrome and supported websites complies with the Chrome Web Store User Data Policy, including applicable Limited Use requirements.

User data is used only to provide or improve PolishPDF's disclosed, user-facing PDF editing functionality.

PolishPDF does not use or transfer user data for personalized, retargeted, or interest-based advertising. PolishPDF does not sell user data.

PolishPDF does not permit routine human access to users' private PDF documents or communications.

16. Children's privacy

PolishPDF is a general productivity application and is not specifically directed toward children. PolishPDF does not knowingly create advertising profiles of children or intentionally collect children's information for advertising purposes.

17. Changes to this Privacy Policy

This Privacy Policy may be updated when PolishPDF's functionality, permissions, data practices, or applicable requirements change. When a material change is made, the effective date at the top of this policy will be updated.

18. Contact

For privacy questions, data-handling questions, or support relating to PolishPDF, users may contact the publisher through the support information provided on the PolishPDF Chrome Web Store listing.
