1. Overview

This Privacy Policy explains how PolishPDF handles information when you use the PolishPDF Chrome extension. PolishPDF's single purpose is to let users open, edit, annotate, reorder, download, and return PDF documents within supported Chrome, Gmail, and Zoho Mail workflows.

Google's Chrome Web Store policies treat locally processed information as user data handling as well. For that reason, this policy describes both information processed on your device and any network activity associated with the extension.

Current product model: PolishPDF does not require a PolishPDF account and does not maintain a PolishPDF-operated cloud database containing your PDF files, email contents, or document edits.

2. Data we handle

PolishPDF may handle the following categories only when needed for the user-facing PDF editing features you choose to use:

User-generated content
PDF files you choose to open, text and annotations inside those PDFs, page order, and edits you make.
Personal communications
A user-selected PDF attachment and limited compose-window context necessary to open or return that attachment in Gmail or Zoho Mail.
Website content
Limited page structure and attachment-related elements on supported Gmail and Zoho Mail pages that PolishPDF needs to detect the user-facing compose/attachment workflow.
Technical data
Normal browser/network metadata may be generated when Chrome loads resources needed by the extension. PolishPDF does not use analytics or advertising SDKs in the current release.

Information we do not intentionally request

PolishPDF does not request your passwords, authentication cookies, precise location, health information, credit information, or browsing history for unrelated sites.

3. How we use data

Information handled by PolishPDF is used only to provide or improve the extension's disclosed PDF editing workflow. This includes:

  • opening and rendering a PDF you select;
  • detecting editable text regions and applying edits or annotations;
  • reordering or deleting pages at your direction;
  • creating the edited PDF output;
  • returning or attaching that edited PDF to the Gmail or Zoho Mail compose workflow you initiated; and
  • diagnosing extension breakage locally through browser console messages.

PolishPDF does not use your PDFs, email content, or attachment content to build advertising profiles, sell data, or train a PolishPDF-owned AI model.

4. Gmail and Zoho Mail access

PolishPDF requests host access to mail.google.com and supported regional Zoho Mail domains. This access exists so the extension can detect PDF attachments in supported compose workflows, open the PDF editor when you request it, and return the edited PDF to the same workflow.

Scope: PolishPDF is not designed to read your inbox for unrelated purposes, profile your email activity, or monitor general web browsing. Supported site access is limited to the extension's PDF editing purpose.

5. Local processing and document transfer

PDF rendering and editing take place inside the Chrome extension environment on your device. The current release does not upload your document contents to a PolishPDF-operated backend for storage or processing.

When you explicitly download, save, or return an edited PDF to Gmail or Zoho Mail, the resulting document is handled by the destination you selected and becomes subject to that service's own privacy terms.

Chrome PDF mode may access the PDF resource that Chrome itself is opening so PolishPDF can render it for editing. PolishPDF does not use that access to create an unrelated browsing-history service.

6. Third-party open-source code

The current PolishPDF release uses open-source PDF rendering technology. In version 0.5.25, Mozilla PDF.js 3.11.174 is loaded from cdnjs.cloudflare.com inside a Chrome sandboxed editor page.

This network request is used to download the library code. PolishPDF does not intentionally transmit your PDF contents, email contents, or attachments to the CDN as part of that request. Like standard web requests generally, the CDN may receive ordinary connection metadata such as an IP address and browser user-agent information under its own terms.

Future releases may bundle these dependencies locally. If the extension's data practices materially change, this policy will be updated before or alongside that change.

7. Storage and retention

Because the current PolishPDF release does not operate a server-side document database, PolishPDF does not retain copies of your PDFs, email contents, or edits on PolishPDF-operated servers.

Document data may remain temporarily in browser memory while an editing session is active. Files that you download, save, or attach are retained wherever you choose to store or send them. Browser console diagnostics may remain available locally until Chrome clears them or the relevant browser session ends.

8. Security

PolishPDF uses Chrome Manifest V3 and limits extension host access to the supported Gmail and Zoho Mail domains required for its user-facing PDF workflow. The PDF editor is configured as a sandboxed extension page, which separates it from privileged Chrome extension APIs.

No software can guarantee absolute security. We design PolishPDF to minimize access and avoid unnecessary server-side document handling, reducing the amount of user data exposed outside the browser.

9. Your choices and controls

  • You decide which PDF to open and edit.
  • You can close PolishPDF without exporting an edited copy.
  • You control whether an edited document is downloaded or returned to an email workflow.
  • You can manage PolishPDF's site access through Chrome's extension settings.
  • You can uninstall PolishPDF at any time through Chrome.
Chrome Web Store Limited Use

10. Limited Use disclosure

PolishPDF's use of information received from supported websites and Chrome complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.

  • Allowed use: user data is used only to provide or improve PolishPDF's single purpose and user-facing PDF editing features.
  • Allowed transfer: PolishPDF does not transfer user data except where necessary to provide the feature the user requested, comply with applicable law, address security or abuse, or as otherwise permitted by the Chrome Web Store User Data Policy.
  • No personalized advertising: user data is not used or transferred for personalized, retargeted, or interest-based advertising.
  • No routine human access: PolishPDF does not permit humans to read private user documents or communications, except where the user affirmatively provides specific content for support, where required for security, where required by law, or where otherwise permitted by applicable policy.

Children's privacy

PolishPDF is a general productivity tool and is not directed specifically to children. The extension does not knowingly create profiles of children or intentionally collect children's information for advertising.

11. Changes to this policy

We may update this Privacy Policy when PolishPDF's functionality, permissions, data practices, or legal obligations change. The effective date at the top of this page will be updated when a revised policy is published.

12. Contact

For privacy questions, data-handling questions, or support related to PolishPDF, contact the publisher through the support channel on the PolishPDF Chrome Web Store listing.

If you voluntarily send a document or message for technical support, we will use that material only to address the support request and will not use it for advertising.
